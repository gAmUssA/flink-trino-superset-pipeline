= Data Pipeline Requirements
:toc:
:icons: font

== Purpose

An end-to-end streaming data pipeline demonstrating real-time data processing with modern open-source technologies, fully containerized for portability.

== Components

* Apache Kafka -- real-time data ingestion (KRaft mode)
* Apache Flink -- stream processing and transformation
* Apache Iceberg -- open table format for lakehouse storage
* SeaweedFS -- S3-compatible object storage
* Trino -- distributed SQL query engine
* Apache Superset -- data visualization and dashboarding
