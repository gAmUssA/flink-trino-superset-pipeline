== Quick Verification

[source,bash]
----
make verify-demo
----

This checks all containers, Flink job status, Iceberg table data, S3 storage, and Superset.

== Step-by-Step Verification

=== 1. Containers Running

[source,bash]
----
make smoketest
----

All 9 services should be up: kafka, minio (SeaweedFS), flink-jobmanager, flink-taskmanager, iceberg-rest, trino-coordinator, superset, data-generator, flink-sql-client.

=== 2. Flink Jobs

[source,bash]
----
# Via UI
open http://localhost:8081

# Via CLI
docker exec flink-jobmanager flink list
----

Expect 2 running jobs: `insert-into_iceberg_catalog.warehouse.user_activity` and `insert-into_iceberg_catalog.warehouse.sensor_data`.

=== 3. Data in Iceberg Tables

[source,bash]
----
make verify-data-flow

# Or query directly via Trino CLI
docker exec -it trino-coordinator trino --server localhost:8080 --catalog iceberg
----

[source,sql]
----
SELECT event_type, COUNT(*) FROM warehouse.user_activity GROUP BY event_type;

SELECT sensor_type, COUNT(*), ROUND(AVG(reading), 2) as avg
FROM warehouse.sensor_data GROUP BY sensor_type;
----

Both tables should have rows with distributed event/sensor types.

=== 4. S3 Storage (SeaweedFS)

[source,bash]
----
# Via SeaweedFS UI
open http://localhost:9001

# Via AWS CLI
docker run --rm --network flink-trino-superset-pipeline_pipeline-network \
  -e AWS_ACCESS_KEY_ID=minioadmin \
  -e AWS_SECRET_ACCESS_KEY=minioadmin \
  -e AWS_DEFAULT_REGION=us-east-1 \
  amazon/aws-cli --endpoint-url http://minio:9000 s3 ls s3://warehouse/ --recursive
----

Expect Parquet data files and Iceberg metadata under `s3://warehouse/warehouse/`.

=== 5. Superset Dashboard

[source,bash]
----
open http://localhost:8088
----

Login with `admin`/`admin`.
The "Streaming Pipeline Analytics" dashboard should show 6 charts with live data.

== Troubleshooting

[cols="1,2",options="header"]
|===
|Problem |Fix

|No data in tables
|Check Flink dashboard (:8081) for running jobs. Verify data generator: `docker logs data-generator`. Iceberg needs ~30s for first checkpoint commit.

|Trino can't find tables
|Tables are created by Flink, not Trino. Deploy Flink jobs first: `make deploy-flink-jobs`. Wait for a checkpoint cycle.

|Flink jobs fail with ClassNotFound
|Rebuild Docker images: `docker-compose up -d --build flink-jobmanager flink-taskmanager`

|S3 storage errors
|Check SeaweedFS health: `docker logs minio`. Verify bucket exists: `docker exec minio curl -sf http://localhost:9000/warehouse/`

|Superset has no dashboard
|Run `make setup-superset` to import the pre-built dashboard.
|===
