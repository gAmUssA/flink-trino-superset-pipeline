== Flink + Iceberg Integration

=== Checkpointing is mandatory for Iceberg writes
Iceberg commits data only during Flink checkpoints.
Without `execution.checkpointing.interval` set, data is buffered in memory but never committed to S3.
Tables appear empty even though the job shows records processed.

=== Use `catalog-type=rest`, not `catalog-impl`
The official Iceberg docs recommend `'catalog-type'='rest'` for the built-in REST catalog.
Using `'catalog-impl'='org.apache.iceberg.rest.RESTCatalog'` is the custom catalog path and may behave differently.

=== Catalog context switches break table references
After `USE CATALOG iceberg_catalog; USE warehouse;`, temporary tables created in the default catalog become invisible.
Fix: use fully-qualified names like `default_catalog.default_database.my_kafka_source`.

=== `iceberg-aws-bundle` replaces individual AWS jars
Individual jars (`iceberg-aws`, `s3`, `hadoop-aws`) miss transitive dependencies.
The `iceberg-aws-bundle` is a single shaded JAR with everything needed for S3FileIO.

=== Caffeine cache is required at runtime
Iceberg 1.8.1's `RESTSessionCatalog` uses Caffeine for catalog caching.
The `iceberg-flink-runtime` jar does not bundle it -- add `caffeine-3.1.8.jar` to Flink's lib.

=== S3 path-style-access must be set in TWO places
SeaweedFS (and MinIO) require path-style URLs (`http://host:9000/bucket/key`).
Without it, the AWS SDK constructs `http://bucket.host:9000/key` which fails DNS.
Set it in both Flink catalog properties AND the REST catalog env (`CATALOG_S3_PATH__STYLE__ACCESS=true`).

== Flink SQL Patterns

=== Prefer SQL jobs over Java Table API for simple pipelines
SQL files in `flink-jobs/sql-jobs/` are declarative and easier to maintain than equivalent Java code.
The Java Table API processors exist for cases needing programmatic control (e.g., nested ROW field access).

=== Nested ROW field access in Table API
`$("location.lat")` does NOT access the `lat` field of a ROW column named `location`.
It looks for a column literally named `location.lat`.
Correct syntax: `$("location").get("lat")`.

=== Watermarks and reserved keywords
`timestamp` is a SQL reserved word.
Always use backticks in DDL: `` WATERMARK FOR `timestamp` AS `timestamp` - INTERVAL '5' SECOND ``.

=== JSON parse error tolerance
`'json.ignore-parse-errors' = 'true'` prevents the entire Flink job from crashing on malformed records.
Bad records are silently dropped.

== Infrastructure

=== SeaweedFS as MinIO replacement
MinIO abandoned its open-source direction in late 2025.
SeaweedFS (Apache 2.0, since 2012) is a drop-in replacement.
Keep the container hostname as `minio` and S3 port as 9000 to avoid cascading config changes.
See https://rmoff.net/2026/01/14/alternatives-to-minio-for-single-node-local-s3/[rmoff's analysis].

=== SeaweedFS health check
`wget --spider` sends HTTP HEAD requests, which SeaweedFS's master endpoint rejects.
Use `curl -sf` instead for health checks.

=== Docker volume permissions for checkpoints
Flink runs as uid 9999 (`flink` user).
Docker named volumes are created as root.
The checkpoint directory `/opt/flink/checkpoints` becomes unwritable.
Fix: use the container's local filesystem instead of a shared volume.

=== Kafka KRaft mode
Apache Kafka 3.9 runs in KRaft mode (no Zookeeper).
Single-node setup with `KAFKA_PROCESS_ROLES=controller,broker`.

== Superset

=== Dashboard export/import
Superset's `import-dashboards -p <zip> -u admin` restores the full dashboard including database connections, datasets, and charts.
The export zip is baked into the Docker image so `make setup-superset` restores everything automatically.

=== Trino connection URI
The correct SQLAlchemy URI for Superset is `trino://admin@trino-coordinator:8080/iceberg/warehouse`.
The `trino` pip package alone is insufficient -- also install `sqlalchemy-trino`.

== Dependency Gotchas

[cols="1,2",options="header"]
|===
|Dependency |Notes

|`iceberg-flink-runtime-1.20`
|Bundles Flink integration but NOT AWS SDK or Caffeine

|`iceberg-aws-bundle`
|Shaded jar with full AWS SDK v2 -- use this instead of individual AWS jars

|`caffeine`
|Required by Iceberg REST catalog client, not bundled anywhere

|`hadoop-common` + `hadoop-hdfs-client`
|Required by `FlinkCatalogFactory.clusterHadoopConf()` at catalog creation

|`httpclient5` + `httpcore5`
|HTTP transport for REST catalog communication
|===
